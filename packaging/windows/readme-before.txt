Scope - oscilloscope and analyser plugin

This installs:
  - Scope.vst3 into C:\Program Files\Common Files\VST3
    (the standard folder every DAW scans)
  - The Scope standalone app (optional)

If Windows shows "Windows protected your PC", click "More info" and then
"Run anyway". This appears because this test build is not code-signed yet.

After installing, open your DAW and rescan plugins if Scope doesn't show up.
In FL Studio: Options > Manage plugins > Find more plugins.
